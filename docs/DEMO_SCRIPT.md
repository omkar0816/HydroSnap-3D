# 5-minute demo script (prototype)

1. **Overview** (30 s) — point at the "Demo data" badge: be honest first.
2. **Map** (90 s) — Map analysis → colour by "Mapped assets" (legend appears) →
   search "Mula" → panel shows code, area, assets, % verified, last inspection →
   switch Street → Satellite (view stays) → toggle 3D.
3. **"Which watershed am I in?"** (20 s) — uses device GPS + point-in-polygon.
4. **Offline capture** (90 s) — DevTools → Network → Offline. Geo-coded images →
   add a photo → enter `18.556, 73.631` → Confirm → watershed auto-set to Mula
   Headwaters → trust panel shows reasons → Save. Topbar: "Offline · 1 queued".
5. **Reconnect** (30 s) — Online → indicator goes "Syncing…" → "All synced".
   Record appears on the map and in Field evidence.
6. **Review** (40 s) — Field evidence → open the record: photo, SHA-256, trust
   reasons, audit trail → Verify → download audit JSON → export CSV/GeoJSON.
7. **Close** (20 s) — LIMITATIONS.md and the roadmap (backend, real satellite).
